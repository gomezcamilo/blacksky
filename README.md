## 📖 Descripción

**BLACK SKY** es una plataforma de red social diseñada para la libre expresión anónima. En un mundo donde la vigilancia es constante, BLACK SKY es tu refugio digital donde tus pensamientos permanecen encriptados y tu identidad protegida.

---

## ✨ Características Principales

- 🔐 **Encriptación de Mensajes** - Tres tipos de encriptación visual (Binary, AES-256, Reverse)
- 🎭 **Anonimato Total** - Identidades protegidas con nicknames
- 🎵 **Integración Musical** - Adjunta música de YouTube, Spotify o SoundCloud a tus publicaciones
- 👥 **Comunidades** - Crea y únete a comunidades temáticas con chat en tiempo real
- 💾 **Posts Guardados** - Guarda publicaciones para verlas después
- 📋 **Boards** - Tableros para pensamientos largos y contenido categorizado
- 🎨 **Estética Cyberpunk** - Diseño oscuro con acentos neón y efectos glassmorphism
- 📱 **Multiplataforma** - iOS, Android y Web

## 🛠️ Stack Tecnológico

| Categoría | Tecnología |
|-----------|------------|
| Framework | Expo v53 + React Native 0.79 |
| Navegación | Expo Router v5 |

| Tipo | Descripción |
|------|-------------|
| **BINARY** | Convierte texto a secuencias de 0s y 1s |

## 🚀 Instalación

### Prerrequisitos

- Node.js 18+
- npm o yarn
- Expo CLI

### Pasos

```bash
# Clonar el repositorio
git clone https://github.com/gomezcamilo/blacksky.git
cd blacksky

# Instalar dependencias
npm install

# Configurar variables de entorno
cp .env.example .env

# Iniciar en modo desarrollo
npm run dev
```

### Comandos Disponibles

| Comando | Descripción |
|---------|-------------|
| `npm run dev` | Servidor de desarrollo |
| `npm run build:web` | Build para web |
| `npx expo start --ios` | Ejecutar en iOS |
| `npx expo start --android` | Ejecutar en Android |
| `npx expo start --web` | Ejecutar en web |
